About WeatherNow

WeatherNow is a real-time weather forecasting application that provides accurate and up-to-date weather information for any location around the world.

Technology Stack
  • Python (Flask)
  • OpenWeatherMap API
  • SQLite Database
  • HTML5, CSS3, JavaScript
  • Bootstrap 5
Features
  • Real-time Weather Information
  • 5 Day Weather Forecast
  • Search History
  • Favorite Cities
  • Dark Mode
  • Responsive Design
API Information

We use OpenWeatherMap API for real-time weather data.

API Provider: OpenWeatherMap

Website: https://openweathermap.org
